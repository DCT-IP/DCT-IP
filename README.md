# Dheeman Chaitanya Thakur

I'm a Mathematics and Computing student at MIT Manipal. I like working close to how computers actually run, and I'm slowly getting better at building backend services that other people can rely on.

Most of what I learn comes from building small things and then breaking them. I'd rather understand one system properly than skim five.

## What I'm working on

**Backend.** Mostly FastAPI at the moment, with PostgreSQL, Redis, and Docker. I'm trying to learn what makes an API hold up under real use: auth done right, sensible logging, tests that catch things, and deploys that don't need prayer.

**Systems.** C has been my main teacher here. Pointers, memory, processes, sockets, and the slow work of writing a tiny database from scratch.

**Security.** I try to think about how things fail. OWASP is a good place to start, and CTFs are a good place to practice. Linux hardening and crypto are on the list.

**Machine learning.** The math side first, then NumPy, Pandas, and scikit-learn, with some PyTorch when I want to see how models get deployed.

## Projects

**[Task Manager API](https://github.com/DCT-IP).** An async REST API with JWT auth, PostgreSQL, Redis, Docker, Pytest, and a CI pipeline on GitHub Actions. It's the project where I've learned the most about how pieces fit together.

**[C Systems Programming](https://github.com/DCT-IP).** Notes and code from working through memory management, data structures, processes, and socket programming, including a small database engine.

**[Cybersecurity notes](https://github.com/DCT-IP).** Writeups from exercises and CTFs covering network security, API vulnerabilities, cryptography, and some reverse engineering.
